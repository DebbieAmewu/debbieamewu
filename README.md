# Debbie Amewu Academic Website

This is a static academic website designed for GitHub Pages.

## Pages

- `index.html` - home/about page
- `research.html` - research page
- `cv.html` - CV page
- `teaching.html` - teaching page
- `styles.css` - shared site styling

## Publish on GitHub Pages

1. Create a new GitHub repository, for example `debbie-amewu.github.io` or `academic-website`.
2. Push these files to the repository's default branch.
3. In GitHub, go to `Settings` -> `Pages`.
4. Set `Source` to `Deploy from a branch`.
5. Select the default branch and `/root`, then save.

GitHub will publish the site at either `https://<username>.github.io/` for a username repository or `https://<username>.github.io/<repository>/` for a project repository.
